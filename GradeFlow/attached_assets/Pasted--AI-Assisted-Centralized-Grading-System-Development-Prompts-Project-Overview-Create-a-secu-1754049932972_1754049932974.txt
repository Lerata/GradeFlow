# AI-Assisted Centralized Grading System - Development Prompts

## Project Overview
Create a secure, cloud-based ML system for government education departments that grades standardized exams faster, cheaper, and more reliably than human-only marking.

## Tech Stack Requirements
- **Frontend**: React.js 18+ with TypeScript, TailwindCSS for styling
- **Backend**: Node.js with Express.js and TypeScript
- **Database**: PostgreSQL with Prisma ORM
- **ML/AI**: Python with FastAPI for ML services, PyTorch, Hugging Face Transformers
- **OCR**: Tesseract.js for client-side, Google Vision API for server-side
- **Authentication**: JWT with role-based access control
- **File Storage**: AWS S3 or Google Cloud Storage
- **Deployment**: Docker containers, AWS/GCP for cloud hosting
- **Real-time**: Socket.io for live updates
- **Security**: bcrypt for password hashing, helmet.js for security headers

3. **Math/Science Answer Grading:**

   - Step-by-step solution validation
   - Formula recognition and verification
   - Partial credit calculation

4. **Grading Pipeline:**
   - Text preprocessing and cleaning
   - Subject classification
   - Answer type detection (essay, short answer, multiple choice)
   - Appropriate model selection and execution
   - Score normalization and confidence calculation

5. **API Endpoints:**
   - POST /grade-single: Grade individual answer
   - POST /grade-batch: Grade multiple papers
   - GET /grade-status/{job_id}: Check grading progress
   - POST /retrain: Model retraining with feedback
   - GET /model-info: Model version and performance metrics

6. **Integration Features:**
   - RESTful API for backend communication
   - Async processing for large batches
   - Error handling and retry mechanisms
   - Logging and audit trail

Include model training scripts and evaluation metrics (Cohen's Kappa, accuracy).
